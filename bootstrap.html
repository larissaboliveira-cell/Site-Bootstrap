Entendendo o Bootstrap

O que é e para que serve?

O Bootstrap é o framework HTML, CSS e JavaScript front-end mais popular do mundo para desenvolvimento de interfaces web responsivas e voltadas para dispositivos móveis.

Ele resolve a complexidade de criar layouts acessíveis e adaptáveis do zero, padronizando componentes visuais e reduzindo drasticamente o tempo de desenvolvimento CSS manual.

Sistema de Grid

O sistema de grid baseia-se em 12 colunas flexíveis. A estrutura organiza-se com:

  • .container: Alinha e centraliza o conteúdo.
  • .row: Cria linhas para agrupar colunas.
  • .col: Cria colunas proporcionais automatizadas.
  • .col-md-*: Define largura de colunas em telas médias (≥768px).
  • .col-lg-*: Define largura de colunas em telas grandes (≥992px).

Design Responsivo

O framework garante visualização fluida em dispositivos como celulares, tablets, notebooks e monitores ultrawide por meio de breakpoints de mídia automáticos.

Componentes Utilizados no Projeto

1. Navbar: Barra de navegação responsiva com colapso em telas menores.
2. Card: Estrutura visual containerizada para exibir produtos com imagens e texto.
3. Buttons: Botões estilizados para chamadas de ação (ex: `btn-primary`).
4. Alert: Caixa de mensagens em destaque para avisos importantes ao usuário.
5. Grid System (Container/Row/Col): Organização estrutural em colunas flexíveis.
